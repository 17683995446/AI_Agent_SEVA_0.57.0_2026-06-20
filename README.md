# SEVA - 自驱永续进化预测修正Agent系统

Self-driven Ever-evolving Predictive Correction Agent System

## 项目简介

SEVA是一个基于预测编码理论的自驱永续进化Agent系统，实现双闭环运行架构：
- **在线实时预测修正**：12阶段核心循环（感知→驱力→目标→预测→决策→安全→执行→误差→学习→记忆→元认知→时序）
- **离线复盘模型进化**：记忆巩固、Replay回放、参数融合

## 核心特性

- **三大驱力引擎**：安全(R_safe)、收益(R_gain)、能效(R_eff)
- **虚拟神经调质系统**：多巴胺/血清素/去甲肾上腺素/乙酰胆碱
- **多层预测模型**：底层GRU + 中层Transformer + 高层GNN，精度加权融合
- **四源贝叶斯误差归因**：感知/模型/动作/环境
- **三层安全架构**：本能安全层 / 价值对齐层 / 元伦理层 + 熔断机制
- **HNSW近似最近邻检索**：简化版向量化优化
- **消息总线架构**：支持优先级队列、TTL、广播、录制回放、线程安全
- **四种仿真环境**：空白/混合/漂移/对抗
